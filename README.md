# outils.ch — le hub

Répertoire animé de tous les micro-outils outils.ch : recherche instantanée, filtres par catégorie,
cartes 3D, aurora animée, particules, parallax. 100 % navigateur.

## Stack
- Next.js 14 (App Router) + TypeScript strict
- React 18, framer-motion
- Catalogue dans `lib/catalog.ts` (44 outils)

## Dev
```bash
npm install
npm run dev
npm run build
```
